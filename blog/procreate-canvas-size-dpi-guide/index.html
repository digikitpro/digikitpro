Best Procreate Canvas Size and DPI for Digital Art

By the DigiKitPro studio · Published 2026-09-14

The best Procreate canvas size depends on where the artwork will be used. Screen artwork is governed mainly by pixel dimensions. Print artwork also needs a physical size and a resolution target. A huge canvas is not automatically better: Procreate says larger canvases offer fewer maximum layers, and texture scale changes with the document.

The formula: pixels = inches × DPI

If you want an 8 × 10 inch print at 300 DPI, the working pixel dimensions are 2,400 × 3,000 pixels. If the artwork is only for a screen, choose pixel dimensions that fit the platform or display; DPI is less important to the on-screen appearance.

Procreate’s official Canvas reference says 300 DPI is the standard starting point for printing and 72–144 DPI is a standard range for screens. Confirm the final requirements with your printer or publishing platform.

Practical starting points

These are starting points, not rules. Your iPad model, layer needs, print size, colour profile, and delivery format should decide the final document.

How to create the document in Procreate

  1. From the Gallery, tap the + icon.
  2. Choose a preset or create a custom canvas.
  3. Enter the width, height, and DPI required for the destination.
  4. Choose a colour profile appropriate to the project. Procreate’s handbook explains that RGB is suited to screens and CMYK is commonly used for print workflows; ask your printer when in doubt.
  5. Check the maximum layer count before starting.

The official Create a Custom Canvas guide confirms that larger dimensions reduce the maximum number of layers available, and that the available maximum also depends on the iPad model.

DPI is not a magic quality switch

Changing DPI without changing pixel dimensions changes the physical size metadata; it does not create new detail. Resampling changes the pixel dimensions and can affect sharpness. Procreate notes that enlarging an image creates new data from existing pixels, which may produce unexpected results.

If you know the final print size, create the canvas at that size and resolution at the start. If you are working for screen, prioritise pixel dimensions and the export requirements.

Why your brushes look different on different canvases

Brushes are resolution-sensitive. A texture mark that reads as a pore on a 4,000-pixel portrait can look like a large dot on a 1,200-pixel canvas. Make a small test sheet on the actual document before judging a brush pack.

This matters for portrait, skin, watercolor, and fine line tools. The Portrait Mastery Kit and Master Line-Art Vault can support different workflows, but neither removes the need to test scale.

When to reduce the canvas

Reduce the dimensions when:

  • your layer budget is too small for the workflow;
  • the iPad becomes slow or difficult to navigate;
  • the artwork is only for screen display;
  • you are still thumbnailing composition;
  • the texture is oversized at the current resolution.

To resize an existing document, use Actions → Canvas → Crop and Resize. Procreate’s official guide distinguishes cropping from resampling; read the dialog carefully before applying a change.

FAQ

Is 300 DPI required for Procreate digital art?

No. It is a common print starting point. Screen artwork is primarily determined by pixel dimensions and the destination’s requirements. DPI matters when a physical size is involved.

What is the best Procreate canvas size for portraits?

Choose the final output first. For a print portrait, calculate the physical size at the printer’s DPI requirement. For practice or screen work, use a size that leaves enough layers for your process and keeps brush texture manageable.

Does a larger Procreate canvas give more detail?

It can provide more pixels, but it also reduces the available layer count and may slow the iPad. More pixels only help if the artwork needs that output size and your workflow can support the document.

Can I change DPI in Procreate later?

You can change DPI from Canvas settings. Procreate’s official documentation notes that changing DPI without changing pixel dimensions changes physical-size metadata rather than adding detail. Resampling is a separate operation and can affect quality.

What colour profile should I use?

Use RGB for screen work and the printer’s requested profile for print when available. Procreate’s custom-canvas documentation explains the general RGB and CMYK distinction; your destination’s specification takes priority.
