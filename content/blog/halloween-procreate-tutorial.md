A spooky scene is mostly a lighting exercise. Start with a quiet value structure, place a warm pumpkin against a cool night, then add fog and sparkle only where they support depth. This Halloween Procreate tutorial uses the current [Halloween Spooky Pumpkin Bundle](/products/halloween-pumpkin-bundle/), [Smoke Procreate Brushes](/products/smoke-brushes-12/), and optional [Glitter Procreate Brushes](/products/glitter-brushes-sparkle-shine-30/).

The Halloween product is listed as 20 pumpkin-themed PNGs at 300 DPI. The PNGs do not require a brush import; the smoke and glitter resources do.

## What you need

- Procreate on iPad for the brush stages.
- A square or portrait canvas matched to the final use.
- One transparent pumpkin PNG or a hand-painted pumpkin.
- A cool dark brush, a soft light brush, smoke texture, and optional sparkle.

If you are new to brush files, start with the [Procreate installation guide](/blog/how-to-install-procreate-brushes/).

## Step 1: Set up the canvas and layers

Create a canvas appropriate for the final post, card, or print. If you are making a print study, use the printer’s dimensions and resolution. Add layers named **Night**, **Moon**, **Ground**, **Fog**, **Pumpkin**, **Glow**, and **Sparkle**. Keeping the effects separate lets you tune the atmosphere without damaging the subject.

## Step 2: Paint a cool night background

Fill the Night layer with a deep blue, indigo, or near-black. Add a lighter area around the moon using a large soft brush. Keep the ground and corners darker so the focal point has room to glow.

Before adding details, squint or zoom out. The moon and pumpkin should already create a readable value hierarchy.

## Step 3: Import the pumpkin PNG

In Procreate, use **Actions → Add → Insert a photo** or the method you normally use to bring a transparent image into the canvas. Place the pumpkin on its own layer and use Transform to set the scale and angle.

Because the product is listed as PNG, it should not need a brush import. If a file arrives compressed, extract it in Files first. The official product artwork shown with this guide is a product visual, not a Procreate screenshot.

## Step 4: Build the warm inner glow

Create a layer above the pumpkin and use a clipping mask if you want the light confined to its shape. Paint a warm orange-yellow inside the face and openings, then place a broader, softer halo on a layer behind or beneath the pumpkin.

Use a suggested low opacity and build the effect gradually. Procreate’s [Blend Modes reference](https://help.procreate.com/procreate/handbook/layers/layers-blend) explains modes such as Screen and Add; test them at low opacity instead of treating a mode as a guaranteed lighting fix.

## Step 5: Add fog for depth

Create fog between the background and pumpkin, then add a second thin layer in front if needed. The catalogue lists 12 smoke brushes in the [Smoke Procreate Brushes](/products/smoke-brushes-12/) set. Use a cool, low-contrast colour and make the fog thicker near the ground, lighter near the moon, and broken around the pumpkin so it does not hide the focal shape.

Vary the scale and direction. Three quiet passes usually create more depth than one heavy stamp.

## Step 6: Finish with sparkle and rim light

Add a few small highlights around the moon, pumpkin glow, or fog edge. The [Glitter Procreate Brushes](/products/glitter-brushes-sparkle-shine-30/) set is optional; avoid scattering equal sparkle over every area.

Use a cool rim light on the shadow side of the pumpkin if the silhouette disappears into the background. Compare the image at thumbnail size and reduce any effect that competes with the face of the pumpkin.

## Common mistakes

- Making the background equally bright everywhere.
- Applying orange glow outside the pumpkin without a layer plan.
- Using dense fog that hides the silhouette.
- Repeating one smoke stamp at the same scale and opacity.
- Adding glitter before the value structure and focal light work.

### Do I need Procreate to use the pumpkin PNGs?

### How do I make a pumpkin glow in Procreate?

Paint warm colour inside the pumpkin on a separate layer, then add a larger low-opacity halo behind it. A clipping mask can keep the inner light inside the shape; a blend mode such as Screen or Add is optional and should be judged at reduced opacity.
