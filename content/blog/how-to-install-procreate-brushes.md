Installing a Procreate brush set is simple once you know which file you are looking for. Most confusion comes from opening the ZIP instead of the extracted `.brushset`, importing a single `.brush` and looking in the wrong set, or trying to use a Procreate file in another app.

The steps below follow Procreate’s official [Importing your brushes help article](https://help.procreate.com/articles/daaqbd-importing-your-brushes). Menu labels can change between app versions, so use the official help page if your interface looks different.

## What the file extensions mean

- **`.brush`** — one Procreate brush.
- **`.brushset`** — a set of brushes imported together.
- **`.brushlibrary`** — a Procreate brush library.
- **`.abr`** — Adobe Photoshop brush files that Procreate’s help documentation also lists as importable.
- **`.zip`** — a compressed folder that must be extracted before you can open the brush file inside.

DigiKitPro’s brush products are described in the catalogue as Procreate `.brushset` downloads, usually delivered as ZIP files. Check the individual product page for the current download structure.

## Step 1: Download the purchase or free resource

Download the file on the iPad you use for Procreate, or transfer it to the iPad with a method such as AirDrop or cloud storage. The file will usually appear in the Files app, often in **Downloads**, **On My iPad**, or **iCloud Drive**.

If you are using the [Free Fine Liner Set](/products/free-fine-liner-brushes-100/) or another free resource, the same file-handling process applies.

## Step 2: Extract a ZIP file

Open **Files** and tap the ZIP once. iPadOS should create a folder with the extracted contents. Open the folder and look for the `.brushset`, `.brush`, or `.brushlibrary` file.

Do not try to import the ZIP itself. If the download contains several ZIP files, extract the one that contains the brushes and keep any PDF guide or bonus files with it.

## Step 3: Import from Procreate’s Brushes panel

Procreate’s official instructions are:

1. Open a canvas in Procreate.
2. Tap **Paint**, **Smudge**, or **Erase** to open the Brush Library.
3. Tap the **+** button in the top-right of Brushes.
4. Choose **Import from Files**.
5. Navigate to the extracted `.brush`, `.brushset`, or `.brushlibrary` file.
6. Tap the file to import it.

An imported single brush appears in an **Imported** brush set. An imported brush set appears near the top of the Brush Library under recently imported sets, according to Procreate’s help article.

## Step 4: Use drag and drop if that is faster

Procreate also supports dragging a brush file from Files or another compatible app into the Procreate interface. In Split View, press and hold the file, drag it to the Brush Library, and release when the app indicates the import target.

If drag and drop feels unreliable, use **Import from Files** instead. Both routes rely on the same file format.

## Step 5: Find and organise the set

Open Brushes and look near the top of the library for a newly imported set. Test one or two brushes on a blank layer before starting a final illustration. Rename or move brushes only after confirming that the full set imported correctly.

For large libraries such as the [Portrait Mastery Kit](/products/portrait-mastery-kit-46-brushes/), [Essential Line Art & Sketch Kit](/products/essential-line-art-sketch-kit/), or a mega bundle, create your own working set with the brushes you actually use.

## If the brush will not import

- Confirm that you extracted the ZIP first.
- Check the extension: a `.brushset` is not the same as a PDF or preview image.
- Re-download if the file appears incomplete or will not open.
- Check that you are opening Procreate for iPad, not another art app.
- Try **Import from Files** instead of tapping the file in another app.
- Check the product requirements and contact the seller if the problem persists.

Do not rename an extension unless the seller or official documentation instructs you to. A renamed file is not necessarily a valid brush file.

## FAQ

### Where do imported Procreate brushes go?

A single imported `.brush` normally appears in an **Imported** brush set. An imported `.brushset` appears near the top of the Brush Library under recently imported sets, according to Procreate’s current help article.

### Can I install Procreate brushes from a ZIP file?

Extract the ZIP in the Files app first, then import the `.brush`, `.brushset`, or `.brushlibrary` inside. Procreate does not need the ZIP itself.

### Why can’t I find Import from Files?

Open a canvas and tap Paint, Smudge, or Erase to open Brushes, then tap the plus button in the top-right. If the interface differs, use Procreate’s official help article for your app version.

### Can I use a `.brushset` in Photoshop?

A `.brushset` is a Procreate brush-set format. Do not assume it will work in Photoshop; check the product page for any bonus formats and software requirements.

### Do DigiKitPro brushes work on iPad?

The brush products linked here are catalogued as files for Procreate on iPad. Confirm the current requirements on the individual product page before downloading or buying.

### I downloaded the file but it is not a brush set. What should I do?

Check whether the download is still compressed, open the extracted folder, and look for the file extension. If the expected brush file is missing or corrupted, contact the product seller with the order and file details.
