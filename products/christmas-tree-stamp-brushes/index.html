How to install it

  1. Complete your order on Payhip, then download the files to your iPad.
  2. If the download is a ZIP, tap it in the Files app to extract the folder first.
  3. Open the extracted folder and tap the .brushset or .brush file to import it into Procreate.
  4. Find the imported set in the Brushes panel. Paper textures, if included, are separate files.

FAQ

What is included in the 25 Christmas Tree Stamp Brushes pack?

The download is a 5MB ZIP containing 25 Christmas tree stamp brushes for Procreate on iPad, ranging from Scandi triangle trees and layered firs to dot-light trees and slim outline silhouettes.

Can I resize and recolour each Christmas tree stamp?

Yes. Pick any color in Procreate, adjust the brush size slider before stamping, or stamp each tree on its own layer to transform, rotate or add ornaments and gold sparkle on top.

How does this compare to the 100 Hand-Drawn Christmas Stamps and the Christmas Bundle?

This pack concentrates specifically on 25 tree silhouettes. For wider holiday icons (wreaths, bells, cocoa, stockings), compare the 100 Hand-Drawn Christmas Stamp Brushes ($5) or the 173-piece Christmas Procreate Brushes Bundle ($8).

What software is required?

An iPad with the Procreate app is required. The stamp brushes do not open in Photoshop or other apps.
