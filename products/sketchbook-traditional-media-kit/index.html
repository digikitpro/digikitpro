About This Product

The Sketchbook Traditional Media Kit combines drawing brushes, canvas files and color palettes for a sketchbook-inspired Procreate workflow. The listing describes 27 brushes, two .procreate canvas files and 13 .swatches palettes.

Use a graphite-style brush for studies or explore the broader charcoal-like marks for larger shapes. The two listed canvas sizes are 3000 × 4000 and 4000 × 6000 pixels at 300 DPI.

How to install it

  1. Complete your order on Payhip, then download the files to your iPad.
  2. If the download is a ZIP, tap it in the Files app to extract the folder first.
  3. Open the extracted folder and tap the .brushset or .brush file to import it into Procreate.
  4. Find the imported set in the Brushes panel. Paper textures, if included, are separate files.
